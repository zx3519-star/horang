FAQ

자주 묻는 질문

설치 시 'Windows의 PC 보호(SmartScreen)' 경고창이 떠요.

코드 서명 인증서(Code Signing Certificate)가 미적용되어 신규 설치 시 윈도우 보안 경고창이 표시될 수 있습니다. 개인 데이터 수집 서버가 전혀 없는 100% 안전한 애플리케이션이므로, 경고창의 [추가 정보]를 누르신 후 [실행] 버튼을 클릭하시면 정상적으로 설치가 진행됩니다.

데이터가 외부 서버로 전송되나요? (외부 통신 안내)

개인 커미션 내역, 가계부, 일정 및 메모는 100% 사용자의 PC 내부(SQLite DB)에만 저장되며 외부 수집 서버는 존재하지 않습니다. 다만 [실시간 환율 조회] 및 [Gemini AI 기능 이용 (BYOK)] 시에만 해당 공식 서비스와 최소한의 필수 외부 통신이 이루어집니다.

AI 기능 사용에 비용이 드나요?

구글에서 무료 발급받은 Gemini API 키를 등록(BYOK)하여 기본 제공 한도로 사용합니다.

지원되는 운영체제는 무엇인가요?

Windows 10 / 11 환경을 지원합니다.
