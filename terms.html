Horang ← 메인으로 돌아가기

서비스 이용 정책

시행일자: 2026년 10월 31일 (이전 버전: 2026년 8월 20일)

1. 목적

본 정책은 '호랑(Horang)' PC 앱(Windows), 모바일 앱(Android·iOS, 휴대폰과 태블릿)과 호랑 AI 번역 브라우저 확장 프로그램(이하 통칭하여 '서비스')의 이용 조건 및 이용자와 개발자 간의 권리·의무를 정합니다.

2. 서비스 제공 및 로컬 중심 동작 원칙

호랑은 프리랜서 및 창작자의 커미션 관리·정산과 번역을 돕는 로컬 설치형 소프트웨어입니다.

  • 사용자가 생성하고 관리하는 모든 작업, 고객, 일정 및 회계 데이터는 사용자의 기기에 저장됩니다. 개발자가 운영하는 데이터 서버는 없습니다.
  • 환율·공휴일 정보 수신, 외부 AI·SMTP·디스코드 연동, 업데이트 확인, 외부 콘텐츠 이용 시 각 제공처와 직접 통신합니다.
  • 브라우저 확장은 사용자가 선택한 텍스트와, 동의한 경우 지원 DM 화면의 최근 대화를 번역 문맥으로 처리합니다.

3. 기기 연동과 구글 드라이브 동기화

  • 기기 연동은 사용자가 직접 짝지은 기기끼리 내부 네트워크에서 데이터를 맞추는 기능입니다. 사용자는 본인이 관리하는 기기만 짝지어야 하며, 짝지은 기기에는 같은 데이터가 저장된다는 점을 알고 사용해야 합니다. 기기를 잃어버리거나 넘길 때는 다른 기기에서 짝짓기를 해제하고 그 기기의 데이터를 지워 주세요.
  • 구글 드라이브 동기화는 선택 기능으로, 사용자 본인의 구글 계정과 저장공간을 사용합니다. 구글 서비스 이용에는 구글의 약관이 적용되며, 저장공간 부족·구글 서비스 장애·계정 정지 등으로 동기화가 늦어지거나 멈출 수 있습니다.
  • 동기화는 여러 기기의 변경을 합치는 기능이며 백업을 대신하지 않습니다. 한 기기에서 지운 데이터는 짝지은 다른 기기에서도 지워질 수 있으므로, 중요한 데이터는 백업 파일을 따로 보관해 주세요.

4. 데이터 소유권 및 백업 책임

앱에 입력된 모든 데이터의 저작권 및 소유권은 전적으로 사용자에게 있습니다. 데이터는 사용자의 기기에 보관되므로, 기기 변경이나 운영체제 재설치 등에 대비한 정기적인 백업 파일 내보내기 및 데이터 보관 책임은 사용자에게 있습니다.

5. 외부 서비스 연동

Google Gemini API, 구글 드라이브, SMTP 메일 서비스, 디스코드, 환율 API 등 외부 연동 기능에는 각 제공처의 약관과 개인정보 처리방침이 함께 적용됩니다. 사용자는 전송할 텍스트·이미지·대화 문맥에 개인정보나 비밀정보가 포함되어 있는지 확인해야 하며, API 키·봇 토큰 관리와 사용량에 따른 비용을 부담합니다. 고객 정보처럼 다른 사람의 개인정보를 앱에 넣고 외부 기능으로 보낼 때는 사용자가 관련 법령에 따라 필요한 동의를 받아야 합니다.

6. 면책 사항

본 소프트웨어는 무료 오픈 환경에서 제공됩니다. 기기 오작동, 운영체제 비호환성, 네트워크·외부 서비스 장애, 동기화 충돌, 예기치 않은 데이터 손실 등으로 인해 발생하는 간접적 손해에 대해 법률이 허용하는 범위 내에서 개발자의 책임이 면책됩니다.

7. 정책 변경

본 정책이 바뀌면 이 페이지의 시행일자를 고치고 앱의 새 소식에서 알립니다. 문의는 GitHub 이슈로 남겨 주세요.
