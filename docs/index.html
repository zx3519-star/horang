설치할 때 Windows 보호 화면이 떠요

무료로 배포하는 프로그램이라 처음 설치할 때 PC 보호 안내가 나올 수 있어요. [추가 정보] → [실행]을 누르면 설치돼요.

어떤 컴퓨터에서 쓸 수 있나요?

Windows 10, 11의 64비트 컴퓨터에서 쓸 수 있어요. 새 버전은 앱이 알아서 받아요.

AI 기능에 돈이 드나요?

호랑이 따로 받는 이용료는 없어요. Gemini는 내 Google 계정의 요금을 따르고, 로컬 모델은 무료예요.

영어나 일본어로도 쓸 수 있나요?

화면 언어는 한국어, 영어, 일본어 중에서 고를 수 있어요.

앱을 지우면 기록도 지워지나요?

지울 때 사용자 데이터 삭제를 고르지 않으면 남아요. 중요한 기록은 설정 > 시스템에서 백업해 두세요.
