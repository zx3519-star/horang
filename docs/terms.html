Horang 서비스 이용 정책

마지막 업데이트: 2026년 8월 4일

1. 목적

본 이용 정책은 '호랑 (Horang)' 데스크톱 애플리케이션(이하 '앱')의 이용 조건, 절차 및 사용자와 서비스 제공자 간의 권리와 의무를 규정함을 목적으로 합니다.

2. 서비스의 성격 및 네트워크 범위

'호랑'은 프리랜서를 위한 무료 온디바이스 데스크톱 워크스페이스 프로그램입니다.

  • 모든 개인 커미션, 가계부, 일정 데이터는 100% 사용자의 PC 내부에만 보관됩니다.
  • 실시간 환율 조회 및 사용자가 발급받은 개인 Gemini API 키(BYOK)를 사용한 AI 기능 연동 시에만 해당 서비스 통신이 실행됩니다.

3. 데이터 소유권 및 백업 책임

앱에 등록하고 입력하는 모든 커미션, 가계부, 일정, 메모 등 데이터의 소유권은 완전히 사용자에게 있으며 외부 수집 서버로 전송되지 않습니다. PC 교체나 데이터 관리에 따른 백업 책임은 사용자 본인에게 있습니다.

4. 외부 AI 및 환율 서비스 이용

구글 Gemini API 및 환율 정보 조회 기능 이용 시, 각 제공처의 API 정책 및 서비스 약관이 함께 적용됩니다.

5. 면책 조항

본 프로그램은 무료로 "있는 그대로(AS IS)" 제공됩니다. 사용자 기기 환경 문제, OS 시스템 오류, 예기치 않은 데이터 손실로 인한 직·간접적 손해에 대해 서비스 제공자는 법률이 허용하는 한도 내에서 책임지지 않습니다.
