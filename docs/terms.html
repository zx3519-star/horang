호랑 서비스 이용약관

마지막 업데이트: 2026년 11월 6일

1. 목적

이 약관은 호랑(Horang) PC 앱(Windows)과 모바일 앱(Android)(이하 '앱')을 이용하는 조건과 사용자와 개발자 사이의 권리·의무를 정합니다. 앱을 설치하거나 이용하면 이 약관에 동의한 것으로 봅니다.

2. 서비스 내용

호랑은 창작자를 위한 무료 커미션·정산 관리 도구입니다. 커미션, 고객, 가격표, 가계부, 일정, 메모 등의 데이터는 사용자의 기기 안에 저장되며, 개발자가 운영하는 서버나 계정 가입은 없습니다.

3. 데이터 소유권과 백업

앱에 입력한 모든 데이터의 소유권은 사용자에게 있습니다. 기기 분실·교체·초기화나 앱 삭제에 대비한 백업은 사용자가 직접 해야 하며, 앱은 이를 위한 백업·불러오기와 기기 연동 기능을 제공합니다.

4. 외부 서비스

  • Gemini AI: 사용자가 직접 발급한 API 키로 이용하며, 그 이용에는 Google의 Gemini API 약관과 요금 정책이 적용됩니다. API 사용 요금은 사용자 계정에 청구됩니다.
  • 구글 드라이브 동기화(선택): 사용자 본인의 Google 계정과 저장 공간을 쓰며, Google 서비스 약관이 적용됩니다.
  • 환율 조회: 공개 환율 API의 값을 참고용으로 보여 줍니다. 실제 정산 환율과 다를 수 있습니다.

5. 사용자의 책임

  • 고객 정보 등 다른 사람의 개인정보를 입력할 때는 관련 법령을 지켜 직접 관리해야 합니다.
  • 앱이 계산한 금액, 수수료, 통계, AI가 만든 문구·번역은 참고용이며, 고객에게 보내거나 세무·회계에 쓰기 전에 사용자가 확인해야 합니다.
  • 앱을 법령에 어긋나는 목적으로 쓰거나, 앱을 변조해 다른 사람에게 배포해서는 안 됩니다.

6. 테스트 버전

Google Play 테스트 트랙 등으로 받은 테스트 버전은 기능이 바뀌거나 오류가 있을 수 있습니다. 중요한 데이터는 미리 백업해 주세요.

7. 변경과 중단

개발자는 앱의 기능을 바꾸거나 업데이트·배포를 중단할 수 있습니다. 약관이 바뀌면 이 페이지에 변경일과 함께 올립니다. 이미 기기에 저장된 데이터는 서비스가 중단되어도 사용자 기기에 남습니다.

8. 면책

앱은 무료로 "있는 그대로" 제공됩니다. 기기·운영체제 문제, 외부 서비스 장애, 사용자의 조작이나 백업 누락으로 생긴 데이터 손실 및 직·간접적 손해에 대해 개발자는 법령이 허용하는 범위에서 책임지지 않습니다.
