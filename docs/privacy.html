Horang ← 돌아가기

개인정보 처리방침

마지막 업데이트: 2026년 11월 4일

이 방침은 호랑(Horang) PC 앱(Windows)과 모바일 앱(Android, 패키지 이름 com.horang.app)에 함께 적용됩니다. 호랑은 개발자가 운영하는 서버가 없으며, 사용자의 데이터를 개발자가 수집하거나 보관하지 않습니다.

1. 기기 안에만 저장되는 데이터

커미션 내역, 고객 정보, 가계부, 일정, 메모, 참고 이미지, 작업 파일 등 앱에 입력한 모든 데이터는 사용자의 기기 안 데이터베이스와 앱 폴더에만 저장됩니다. 광고, 분석, 추적 도구는 쓰지 않습니다.

2. 기기 권한과 쓰는 목적

  • 카메라·사진: 커미션 참고 이미지를 찍거나 고를 때만 씁니다. 사진은 시스템 사진 선택기로 사용자가 고른 것만 앱에 들어옵니다.
  • 마이크: 말로 커미션을 등록하거나 음성 메모를 남길 때만 녹음합니다.
  • 알림: 마감·일정 알림을 보여 줍니다.
  • 알림 접근(선택, Android): 사용자가 설정에서 직접 켠 경우에만, 결제·입금 알림 가운데 금액과 승인·입금 같은 말이 있는 알림을 읽어 가계부 후보로 앱 안에 저장합니다. 다른 알림은 저장하지 않으며, 읽은 내용은 기기 밖으로 보내지 않습니다(아래 4번 기기 연동으로 사용자의 다른 기기에 옮겨질 때 제외).
  • 내부 네트워크: 사용자가 짝지은 PC·폰·태블릿끼리 데이터를 맞출 때 씁니다.

3. 외부로 통신하는 기능

아래 기능을 쓸 때만, 각 서비스의 공식 API와 통신합니다.

  • Gemini AI (사용자 키): 사용자가 직접 등록한 Gemini API 키로 번역, 의뢰 분석, 가격표 만들기, 챗봇, 음성 입력을 요청하면 그 요청에 필요한 글·이미지·녹음이 Google AI 서버로 전송됩니다. 전송된 데이터는 Gemini API 약관과 Google 개인정보처리방침에 따라 처리됩니다.
  • 환율 조회: 외화 금액을 환산할 때 공개 환율 API에서 환율만 받아 옵니다. 사용자 데이터는 보내지 않습니다.
  • 앱 업데이트 확인: PC 앱은 GitHub 릴리즈를, 모바일 앱은 Google Play를 통해 새 버전이 있는지 확인합니다.

4. 기기 연동과 구글 드라이브 (선택)

사용자가 짝지은 기기끼리는 내부 네트워크로 직접 데이터를 맞추며, 주고받는 내용은 암호화됩니다. 구글 드라이브 동기화를 켜면 사용자 본인의 구글 드라이브 안 앱 전용 숨은 폴더(drive.appdata 권한)에 암호화된 변경 기록만 올려 다른 기기가 받아 가게 합니다. 드라이브의 다른 파일은 읽거나 쓰지 않으며, 개발자는 이 데이터에 접근할 수 없습니다.

5. 데이터 관리와 삭제

데이터는 사용자의 기기와 사용자 본인의 구글 드라이브에만 있으므로 사용자가 직접 관리합니다. 앱 안에서 프로필을 지우거나 앱을 삭제하면 그 기기의 데이터가 지워집니다. 구글 드라이브에 올린 동기화 기록은 앱에서 드라이브 동기화를 끄거나, 구글 드라이브 설정의 "앱 관리"에서 호랑의 숨은 앱 데이터를 삭제해 지울 수 있습니다.

6. 아동

호랑은 성인 창작자를 위한 업무 도구이며, 아동을 대상으로 하지 않습니다.
