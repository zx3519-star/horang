Horang ← 돌아가기

개인정보 처리방침

시행일자: 2026년 10월 31일 (이전 버전: 2026년 8월 20일)

호랑(Horang)은 별도의 중앙 데이터 수집 서버 없이 동작하는 로컬 기반 애플리케이션입니다. 본 방침은 호랑 PC 앱(Windows), 호랑 모바일 앱(Android·iOS, 휴대폰과 태블릿)과 호랑 AI 번역 브라우저 확장 프로그램에서 데이터가 처리되는 방식과 범위를 설명합니다. 개발자는 사용자의 데이터를 수집·열람·판매하지 않으며, 광고나 사용 통계 수집 기능도 넣지 않습니다.

1. 로컬 데이터 보관

등록된 커미션 내역, 가계부, 일정, 메모, 고객 정보, 첨부 이미지와 각종 설정은 사용자의 기기 내부 데이터베이스와 폴더에 저장됩니다. Gemini API 키, SMTP 비밀번호, 디스코드 봇 토큰, 구글 로그인 정보 같은 비밀 값은 운영체제가 제공하는 보안 저장소(Windows 데이터 보호, Android Keystore, iOS 키체인)로 잠가 보관하며 동기화나 백업에 싣지 않습니다. 다만 사용자가 아래 기능을 이용하면 그 기능에 필요한 데이터가 해당 기기나 제공처로 직접 전송됩니다.

2. 기기 연동(내부 네트워크 동기화)

사용자가 기기 연동에서 PC·휴대폰·태블릿을 짝지으면, 같은 내부 네트워크에 있는 짝지은 기기끼리 커미션·가계부·일정 등 앱 데이터의 변경 내용을 직접 주고받습니다. 인터넷 서버를 거치지 않으며, 짝지을 때 확인한 기기끼리만 암호화된 연결로 통신합니다. 기기를 찾기 위해 기기 이름과 연결용 식별자 같은 최소 정보를 내부 네트워크 안에 알립니다. 짝짓기를 해제하면 그 기기와 더 이상 동기화하지 않습니다.

3. 구글 드라이브 동기화(선택)

사용자가 "밖에선 구글 드라이브로 동기화"를 켜면, 짝지은 기기들이 서로 다른 네트워크에 있을 때도 데이터를 맞추기 위해 사용자 본인의 구글 드라이브를 우편함처럼 사용합니다.

  • 요청하는 권한: 구글 드라이브의 앱 전용 숨은 폴더(appDataFolder)에만 접근하는 drive.appdata 권한 하나만 요청합니다. 사용자의 다른 드라이브 파일·문서·사진은 보거나 바꿀 수 없습니다. 연결한 계정을 화면에 보여 주기 위해 계정 이메일 주소를 확인합니다.
  • 올리는 데이터: 앱 데이터의 변경 기록을 짝지은 기기끼리만 아는 열쇠로 암호화(AES-GCM)한 상자와, 기기별 진행 상황(마지막으로 받은 위치·시각)만 올립니다. 암호화 열쇠는 내부 네트워크 기기 연동으로만 전달되며 구글 드라이브에 올라가지 않으므로, 구글이나 개발자는 내용을 읽을 수 없습니다. 첨부 이미지 같은 작업 파일은 올리지 않습니다.
  • 로그인 정보: 구글 로그인은 운영체제의 브라우저에서 진행하며, 앱은 비밀번호를 받지 않습니다. 발급된 로그인 정보(refresh token)는 각 기기의 보안 저장소에만 보관합니다. 사용자가 원하면 짝지은 기기끼리 내부 네트워크 기기 연동의 암호화된 연결로 이 로그인 정보를 넘겨, 기기마다 다시 로그인하지 않게 할 수 있습니다.
  • 끄기와 삭제: 스위치를 끄면 그 기기에 보관한 로그인 정보를 지웁니다(짝지은 다른 기기의 연결은 유지됩니다). 드라이브에 남은 상자는 모든 기기가 받아 간 것부터 앱이 스스로 정리하며, 구글 계정의 "타사 앱 및 서비스" 설정에서 호랑의 접근 권한을 취소하면 모든 기기의 연결이 끊기고 숨은 폴더 데이터도 삭제할 수 있습니다.
  • 구글 API 데이터 사용 원칙: 호랑이 구글 API로부터 받은 정보를 사용하고 다른 앱으로 전달하는 방식은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다. 받은 정보는 동기화 기능을 제공하는 데만 쓰며, 광고·판매·AI 모델 학습에 쓰지 않고 사람이 열람하지 않습니다.

4. 외부 네트워크 통신 범위

앱은 다음 기능을 제공하기 위해 해당 서비스와 직접 통신할 수 있습니다.

  • 실시간 환율 조회: 외화 환산 및 페이팔 수수료 계산을 위해 공공 환율 API 서버로부터 기준 환율 정보를 수신합니다.
  • 국가별 공휴일 조회: 일정에 공휴일을 표시하기 위해 앱 언어에 대응하는 국가 코드와 조회 연도만 Nager.Holidays API로 전송합니다. 일정이나 개인 정보는 전송하지 않습니다.
  • Gemini AI 연동(BYOK): 사용자가 AI 분석·생성·번역이나 챗봇을 실행하면 입력한 텍스트, 첨부 이미지와 사용자가 포함하기로 한 대화 문맥·앱 데이터가 개인 Gemini API 키와 함께 Google Gemini API로 전송됩니다. 개발자 서버를 경유하지 않으며 Google의 약관과 데이터 처리 정책이 적용됩니다.
  • 기기 안 AI 모델(선택): 사용자가 내려받기를 고르면 공개 AI 모델 파일을 Hugging Face에서 내려받습니다. 내려받은 뒤에는 기기 안에서만 동작합니다.
  • 디스코드 앱 연동(PC, 선택): 사용자가 디스코드 봇 토큰을 넣으면 PC 호랑이 디스코드에 직접 연결되어, 사용자가 메뉴로 고른 메시지(글·첨부 이미지·링크)만 번역하거나 커미션 임시저장으로 가져옵니다.
  • 이메일 발송: PC에서는 수신 주소, 제목, 본문과 첨부파일이 사용자가 등록한 SMTP 제공자 및 수신 메일 서버로 전송됩니다. 모바일에서는 기기의 메일 앱이나 공유 기능으로 넘기며, 보내기는 사용자가 그 앱에서 직접 합니다.
  • 소프트웨어 업데이트: PC는 새 버전 확인과 설치 파일 다운로드를 위해 GitHub Releases와, 모바일은 새 버전 확인을 위해 Google Play·App Store와 통신할 수 있습니다.
  • 외부 콘텐츠 및 링크: 사용자가 외부 이미지 URL을 가져오거나 후원·API 키 발급 등의 링크를 열면 해당 웹사이트와 통신합니다.

5. 모바일 앱의 기기 권한

  • 사진: 사용자가 커미션에 이미지를 붙일 때만 사진 선택 화면을 열어, 고른 사진만 앱 안으로 복사합니다.
  • 로컬 네트워크: 기기 연동으로 내부 네트워크의 짝지은 기기를 찾고 통신하는 데 씁니다.
  • 백그라운드 작업: 앱이 닫혀 있을 때도 운영체제가 허락하는 범위에서 짝지은 기기·구글 드라이브와 동기화하는 데 씁니다.

6. 브라우저 확장 프로그램

확장 프로그램은 모든 웹사이트의 입력칸과 페이지에서 사용자가 선택한 텍스트에 번역 UI를 제공하기 위해 웹페이지 접근 권한을 사용합니다. 지원되는 DM 화면에서는 번역 정확도를 높이기 위해 선택 문장 주변의 최근 대화 최대 6개를 기기 안에서 추출해 번역창에 미리 보여줍니다. 사용자가 문맥 사용을 켠 상태로 번역하기를 눌렀을 때만 선택 문장과 문맥이 Native Messaging을 거쳐 Gemini API로 전송됩니다. 확장 프로그램은 대화 내용이나 번역 결과를 별도로 저장하지 않으며, 기기에는 선택한 번역 언어와 톤 설정만 저장합니다.

7. 데이터 관리, 백업 및 삭제

설정에서 백업을 내보내거나 불필요한 데이터를 삭제할 수 있습니다. PC 앱 안의 제거 기능에서 사용자 데이터 삭제를 선택하면 프로필, 설정, 데이터베이스와 자동 백업이 함께 삭제됩니다. 해당 옵션을 선택하지 않거나 운영체제에서 앱만 제거하면 데이터가 남을 수 있습니다. 모바일 앱을 제거하면 그 기기의 앱 데이터와 보안 저장소의 값이 함께 삭제됩니다. 짝지은 다른 기기에 동기화된 데이터는 그 기기에 그대로 남으며, 구글 드라이브의 숨은 폴더 데이터는 3항의 방법으로 삭제할 수 있습니다. 확장 프로그램을 제거하면 브라우저가 보관한 언어·톤 설정도 삭제됩니다.
