Horang ← 돌아가기

개인정보 처리방침

마지막 업데이트: 2026년 8월 4일

Horang은 사용자의 프라이버시를 존중하며 데이터의 안전성을 최우선으로 설계된 데스크톱 앱입니다.

1. 로컬 데이터 보관 (온디바이스 Storage)

모든 커미션 내역, 가계부, 일정 및 메모는 사용자의 PC 내부 로컬 데이터베이스(SQLite-WASM)에만 저장됩니다. 사용자의 개인 데이터는 외부 개발자 서버로 전송되거나 수집되지 않습니다.

2. 필수 외부 네트워크 통신 안내

앱의 원활한 기능 제공을 위해 아래 2가지 기능 이용 시에만 최소한의 공식 API 통신이 수행됩니다:

  • 실시간 환율 정보 조회: 페이팔 정산 및 외화 환산 계산을 위해 공식 환율 정보 API 수신 통신이 수행됩니다.
  • Gemini AI 기능 연동 (BYOK): 사용자가 직접 등록한 개인 Gemini API 키를 통해 번역, 의뢰 분석, 가격표 생성 요청 시 텍스트/이미지 정보가 구글 AI 서버로 전송됩니다.

3. 데이터 관리 및 삭제

모든 개인 데이터는 사용자의 PC에 완전히 종속 보관되므로, 앱 삭제 시 로컬 데이터베이스와 함께 즉시 제거됩니다.
